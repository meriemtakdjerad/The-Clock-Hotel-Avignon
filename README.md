# The Clock Hotel Avignon - Gestion des Réservations

## Description
Ce projet est une application web de gestion des réservations pour "The Clock Hotel Avignon", permettant aux utilisateurs de consulter, ajouter, modifier et supprimer des réservations.

L'application fournit une interface simple et intuitive, avec un système de filtrage et de pagination pour gérer les réservations en cours.

---

## Fonctionnalités

### Page d'accueil
- Présentation de l'hôtel avec des images et une description du lieu.
- Accès au menu pour naviguer entre les différentes sections de l'application.

### Gestion des réservations
- **Lister les réservations existantes** : Tableau paginé avec des colonnes pour l'ID, le nom, la taille de la chambre, la durée du séjour, et des actions pour modifier ou supprimer une réservation.
- **Ajouter une réservation** : Formulaire permettant de renseigner un nom, une taille de chambre et une durée de séjour.
- **Modifier une réservation** : Modifier les informations d'une réservation existante.
- **Supprimer une réservation** : Supprimer une réservation via une icône d'action.

### Navigation
- **Menu latéral** : Accès rapide à la présentation de l'hôtel, à la création de nouvelles réservations, ou à la liste des réservations existantes.

---

## Structure du Projet

### Fichiers Principaux
- **index.html** : Page principale de l'application.
- **init.html** : Page d'accueil présentant l'hôtel.
- **index.php** : Gestion des fonctionnalités principales (liste et formulaire).
- **modifresa.php** : Gestion de la modification des réservations.
- **reservations.php** : Logique liée à la suppression et l'affichage des réservations.
- **listederesarvations.txt** : Fichier texte contenant des données pour les réservations (simulation de base de données).

### Ressources
- **meriem.jpg** : Image utilisée pour illustrer la présentation de l'hôtel.

---

## Prérequis

- Serveur Web (Apache, Nginx ou autre).
- PHP (version 7 ou supérieure).
- Navigateur compatible avec HTML5 et CSS3.
